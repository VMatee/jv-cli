# JV CLI 0.4.9

- Adds `jvcli bridge --stdio`, a versioned machine NDJSON interface for Linux.
- Preserves existing terminal commands, JSON output, sessions and permissions.
- Bridge passwords are memory-only and are not persisted.
- Bridge image requests remain deferred; existing terminal image support is unchanged.

Normal and offline Linux x86_64 packages include checksums. Existing installations
can use the verified `upgrade.sh` mechanism, preserving settings, sessions and runtime.
