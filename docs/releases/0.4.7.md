# JV CLI 0.4.7

## What's new

- Type `/` in an interactive terminal to see available commands. Narrow the list by typing, use Tab to complete, or choose with arrow keys and Enter.
- Slash commands remain in English. Descriptions and spelling suggestions are available in Thai. A misspelled slash command stays local and does not submit a task.
- Use `/exit` to leave and keep your saved account, or `/logout` to leave and forget it.
- Type tasks in Thai. JV CLI asks the assistant to reply in the task's language when practical, while preserving code and command names.

The menu appears in interactive terminals. Piped input keeps the existing line-input behavior.

## Install or update

Download the Linux x86_64 ZIP and matching SHA-256 file from the published release, then follow the [installation and update guide](https://github.com/VMatee/jv-cli#install). Close existing sessions before updating. Check with `jvcli --version` and `jvcli doctor`.
