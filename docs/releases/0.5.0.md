# JV CLI 0.5.0

- Native Windows 10/11 AMD64 support with a per-user installer and portable ZIP.
- The Windows package includes its required runtime; no separate Python, Node or Codex installation is needed.
- Dedicated Windows workers explicitly select `--execution-mode trusted-host`: full tool filesystem access, network enabled and no tool approval prompts.
- Saved state stays separate from application binaries. Reinstall and normal Windows uninstall preserve state.
- Linux normal and offline packages, existing permission modes and bridge protocol 1 remain supported.

Install Windows JV CLI before JV Desktop. Run `jvcli --version`, `jvcli doctor`,
and `jvcli bridge --stdio --execution-mode trusted-host` to check setup.

Use an ordinary dedicated Windows account and keep Windows Firewall enabled.
Trusted-host is not sandboxed. Windows requests requiring network isolation remain
unsupported and fail closed. Stop cancels local execution; remote work may remain
unknown. Windows ARM64 and network-share installations are unsupported.

The Windows installer is unsigned and may trigger SmartScreen/publisher warnings.
Verify downloads against the release's `SHA256SUMS`. Checksums verify bytes, not
publisher identity. Linux `.sha256` files remain available for existing installers.
