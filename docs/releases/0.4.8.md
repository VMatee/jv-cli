# JV CLI 0.4.8

## What's new

- Download one offline ZIP to install JV CLI on Ubuntu/Linux x86_64 without npm or a dependency download. It includes the JV CLI source, the pinned agent engine, and Node.js.
- The offline installer checks its bundled files and verifies the engine before installing it. The smaller online ZIP remains available.

Python 3.10+ and standard Linux system libraries are still required. Sign-in and AI tasks still need a connection to the JV service.

## Install

Download `jv-cli-0.4.8-linux-x86_64-offline.zip` and its matching `.sha256` file below. Follow the [offline installation guide](https://github.com/VMatee/jv-cli#install-without-downloading-dependencies), then run `jvcli --version` and `jvcli doctor`. Installation is per-user and does not need `sudo`.
