# JV CLI 0.5.3 — prepared source, release pending

- Compatible desktop clients can explicitly select Structured sessions for
  image-assisted coding. The agent can inspect PNG, JPEG and WebP files and
  continue editing and testing the project afterward.
- Legacy sessions remain available. An unsupported Structured service reports
  its support code without automatically submitting the task again in Legacy.
- Windows Structured sessions send the certified patch declaration in the form
  expected by compatible services, preserving the original patch contents.
- Windows continues to require explicit trusted-host execution on a dedicated
  worker account, with full tool filesystem/network access and no approval prompts.

Prepared pairing: JV CLI 0.5.3 and JV Desktop 0.2.3. Install CLI first, then
Desktop. Windows candidates are unsigned; verify each downloaded installer
against the checksum supplied with its pre-release before installing.

These notes describe the prepared source. Final Windows installer acceptance
and cross-platform publication are pending. Published stable installation links
continue to select 0.5.2 until the official 0.5.3 release is available.
