## What's new

- Clearer messages distinguish provider output rejection and cleanup failures from errors in project commands.
- Failed remote responses stop safely without automatic resubmission.
- Completed command results and saved sessions remain available for diagnosis after a remote failure.
- Remote error text is replaced with stable, actionable descriptions.

These changes improve failure reporting and preserve the existing single-submission safety behavior. They do not change workspace permissions or account requirements.

## Install or update

Download the Linux x86_64 ZIP and matching SHA-256 file below. Follow the [installation and update guide](https://github.com/VMatee/jv-cli#install), then check your setup with `jvcli --version` and `jvcli doctor`.

Requires Python 3.10+, Node.js 18+, npm, internet access, and an existing JV account. Close running sessions before updating. Installation is per-user and does not require administrator privileges.

See the [changelog](https://github.com/VMatee/jv-cli/blob/main/docs/CHANGELOG.md) for earlier improvements. Always review generated changes and test important workflows before relying on them.
