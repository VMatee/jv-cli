## What's new

- More careful completion guidance for files affected by failed or interrupted commands.
- Clearer instructions to recheck file contents instead of relying only on file existence or size.
- Improved guidance for starting fresh from an incompatible saved session.

Review generated files and run your project's tests before relying on the results. Completion guidance does not guarantee correctness for every task.

## Install or update

For the current package and instructions, use the [latest release](https://github.com/VMatee/jv-cli/releases/latest) and [installation guide](https://github.com/VMatee/jv-cli#install). Close running sessions before updating and verify the download checksum.
